/api/claude

The serverless function must securely call:

https://api.anthropic.com/v1/messages

using:

process.env.ANTHROPIC_API_KEY

The API key must only exist as an environment variable.

The frontend must NEVER contain:

ANTHROPIC_API_KEY
the actual API key
or any hardcoded secret.

The serverless function should:

1. Receive the frontend request.
2. Validate the request.
3. Call Anthropic Claude.
4. Use model claude-sonnet-4-20250514.
5. Return the AI response to the frontend.
6. Handle API errors safely.
7. Never expose the API key.

Use fetch() for all frontend communication with /api/claude.

The main UI, CSS, and frontend JavaScript must remain inside index.html.
